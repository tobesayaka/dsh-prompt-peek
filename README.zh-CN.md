# dsh-prompt-peek

[English](README.md) | **简体中文**

**给 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 网页版输入框带来 Shell 风格的提示词回翻，以及带 Markdown 渲染的回答预览。**

在空输入框按 `↑` 翻回上一条你发过的消息，继续按往更早翻，`↓` 往新翻。`Ctrl+R` 搜索当前会话的提示词，选中后按 `空格` 预览 dsh 当时的回答。

## 功能

- **回翻** — 上下方向键按时间倒序翻阅当前会话里你实际发过的消息，连续重复的会合并；插件安装前发出的消息也会包含。
- **搜索** — `Ctrl+R` 在输入框上方打开浮动面板，实时过滤并高亮匹配。搜索框是真实输入框，中文/日文输入法可以正常工作。
- **预览** — 在选中的消息上按 `空格`，渲染 dsh 当时给出的回答：取收尾的助手文本，排除工具调用和推理，按 Markdown 渲染（标题、列表、任务列表、引用、代码块、对齐表格，链接仅允许安全协议）。代码块交给宿主自带的 Shiki `CodeBlock` 渲染，两种主题下都有语法高亮，并保留语言标签和聊天回答里的复制、换行控件。
- **平滑翻页** — `PgUp` / `PgDn` 在长回答里缓动滚动而不是直接跳。连续按会接力成一段连续运动，滚轮、触摸或拖动滚动条会立即接管，`prefers-reduced-motion` 下回退为直接跳转。
- **零足迹** — 不写任何数据，也不发出任何请求；历史按需从会话自己的事件窗口读取。

## 按键

### 输入框

| 按键 | 作用 |
| --- | --- |
| `↑` | 回翻上一条提示词。仅在空输入框开始，之后可持续翻阅。 |
| `↓` | 往较新的提示词翻；超过最新一条后清空输入框。 |
| `Esc` | 退出历史翻阅（回填的文字保留在输入框）。 |
| `Enter` | 发送回填的提示词，和手动输入完全一样。 |
| `Ctrl+R` / `Cmd+R` | 打开当前会话提示词的反向搜索。 |

### 搜索面板

| 按键 | 作用 |
| --- | --- |
| `↑` / `↓` | 选择匹配项。 |
| `空格` | 切换所选提示词对应回答的 Markdown 预览。 |
| `Shift+空格` | 在搜索框中输入一个普通空格。 |
| `PgUp` / `PgDn` | 让回答预览平滑滚动设置里的「每页滚动距离」（默认 270 px，约 15 行）；长按连续滚动，松开即停。预览还没打开时，第一次按下会先打开预览并翻一页；到顶或到底后再按时改为切换上一条 / 下一条，而不是毫无反应。 |
| 鼠标滚轮 | 预览打开时，在搜索框上滚动滚轮，一格滚动四分之一页（「每页滚动距离」的 1/4）。 |
| `Enter` | 把选中的提示词填入输入框。 |
| `Esc` | 关闭搜索。 |

搜索框获得焦点时 `空格` 专用于预览，因此查询中需要空格时请用 `Shift+空格`；面板底部会同时提示两者。翻阅历史时，输入框上方的小胶囊会显示当前位置（`History 3/12`）。

## 设置

插件在 **设置** 里有自己的分区：侧栏一行 **输入框速览**，排在「Shell」和「内置插件」之间，偏好在独立页面里调整，而不是挤在内置插件分区的标签页里。语言放在最上面一组，选完立即生效；行为几项一起保存，因为它们是一整套策略。

| 设置项 | 默认值 | 作用 |
| --- | --- | --- |
| 界面语言 | 跟随 DSH 界面语言 | 选 `中文` 或 `English` 后，插件的搜索面板、历史胶囊和这个设置页都固定为该语言，即使 DSH 本身用另一种语言。通过右上角的地球菜单切换，选完即保存。选 **跟随 DSH 界面语言** 时实时读取 DSH 当前语言（`zh-CN` 这类标签也算中文），DSH 切语言时面板与设置页一起跟着变。 |
| 显示回答预览 | 开 | 关掉后 `空格` 不再打开回答预览。搜索面板底部会说明这一点，并提供「重新开启」按钮，点一下就会保存设置并立刻恢复预览，不用去设置页。 |
| 平滑翻页 | 开 | `PgUp` / `PgDn` 和滚轮是平滑滚动而不是直接跳动；系统要求「减少动态效果」时始终直接跳。 |
| 每页滚动距离 | 270 px（约 15 行） | 一次 `PgUp` / `PgDn` 让预览移动的距离；鼠标滚轮一格移动它的四分之一。预览到顶 / 到底后，`PgUp` / `PgDn` 改为切换上一条 / 下一条提示词，不会「按了没反应」。 |
| 历史条数上限 | 300 | 回翻和搜索最多读取当前会话最近多少条提示词。 |
| 结果顺序 | 从新到旧 | `从旧到新` 是 ARIA 列表框的常见顺序；要让选中的提示词紧挨输入框，请用 Shell 习惯的 `从新到旧`。 |

**保存**提交整张表单；**恢复配置默认值**删除设置文件。保存后已打开的输入框立即生效，无需刷新页面。

设置存放在 `~/.dsh/prompt-peek/settings.json`（文件权限 `0600`），而不是 DSH 的用户设置文档——同一个 DSH home 下可能有多个 profile 安装同一份本地 checkout，这样它们共用一套偏好。文件里只有以上六个字段，**不保存**提示词、回答或任何会话内容。`cordis.patch.yml` 的 `config` 是基线，设置文件只存覆盖项。

## 安装

### 要求

- DSH 0.2.x 网页版 GUI。
- 无构建步骤、无运行时依赖，bundle 是纯 JavaScript。

### 从插件页面安装

1. 打开 DSH 侧边栏的 **Plugins** 页面。
2. 在安装入口填入 bundle spec：本地 checkout 用这个目录的绝对路径即可；发布到 npm 后也可以直接用包名。
3. 如果 bundle 没有自动启用，请手动启用。如果网页没有立即加载，刷新一次页面；无法热组合新 bundle 的宿主需要重启 DSH。

### 从 agent 会话安装

同样可以用 `plugin_manager` 的 `install_bundle`，把本目录作为 `target`。

## 工作原理

插件在输入框的 `conversation.input.overlay` 槽注册一个条目。该条目在输入框卡片上挂一个捕获阶段的键盘监听，因此能在 Lexical 之前拿到按键；它通过输入框自己的 `inputActions.setDraft()` 写入草稿，而不是直接操作编辑器 DOM。

历史和回答预览读的是同一份扫描结果：人类消息是 `source.kind === 'user'` 的 `user/message`，助手消息是任何带 `data.message.content` 文本的事件，其余事件（编辑、替换、工具调用）原地保留、不再遮挡邻居；「历史条数上限」在折叠连续重复之后截取最新的 N 条。回答预览从选中的提示词向后走到下一条人类消息；提示词自身的文本同时作为匹配键，所以即使列表和预览之间事件窗口被重建，也能对上。很长的提示词保留末尾 400 字符；如果第一个搜索命中出现在更早的位置，窗口会向前扩展到 6000 字符并标记命中的段落，预览随即滚到那里——这样选中的列表行就能展示「为什么它匹配」。

宿主侧提供设置路由 `GET` / `POST /api/prompt-peek.settings`（读取、保存补丁、或 `{ "reset": true }`），注册在 Connection 共享的 `/api` 处理器上，因此与其他插件路由一样带 cookie、Host/Origin 和 Peer 校验。Connection 声明在可选的子 fiber 里，没有它的 profile 也能正常加载插件。设置页打开时读取一次；页面本身注册在 `settings.section` 与 `settings.section.icon` 槽，自带侧栏名称和地球图标。

设置页关闭时插件使用文档里的默认值；本次会话中保存过的值会立刻应用到所有已打开的输入框。只有选择「跟随 DSH 界面语言」时，插件才跟随 DSH 切换语言；固定语言时插件文案保持不变。

没有构建步骤和依赖：整个客户端部分都是 `src/client.js` 里的纯 JavaScript，包括 Markdown 渲染器和预览滚动动画。它只通过 Web 外壳冻结的平台模块表接触宿主：用 `react` 渲染界面，用 `@deepseek-ai/dsh-client-ui-primitives` 的共享 `CodeBlock` 渲染代码；宿主没有导出该组件时，回退为带语言标签的普通 `<pre>`。

## 开发

1. 从本目录安装 bundle。
2. 修改 `src/client.js`。
3. 重新加载客户端模块：在 Plugins 页面禁用再启用该 bundle（推荐 HMR），或在宿主无法重新组合时刷新页面 / 重启 DSH。

- `npm test` 运行宿主侧设置测试（`test/settings.test.mjs`，基于 `node:test`）：校验、落盘、重置、坏文件回退。测试使用临时 `DSH_HOME`，不碰真实数据。同时运行 `test/client.test.mjs`：用 `vm` 在无浏览器环境加载客户端工厂，检查它导出的纯函数——语言解析、按键决策、以及逐帧模拟预览翻页。
- `npm run check` 对两个入口执行 `node --check`。
- 客户端改动需要刷新页面或禁用再启用 bundle；宿主改动需要重启 DSH。
- 修改 `glideStep`、`glideFrame`、`pagePlan` 或 `translateKey` 之前，先读 [docs/REGRESSIONS.md](docs/REGRESSIONS.md)，并按里面的方法做反向验证：把旧代码放回去，确认对应测试会失败。

## 已知限制

- 历史只覆盖会话事件窗口中**已加载**的部分，不是超长会话的完整生命周期。
- 历史按会话隔离；全新会话从空开始。
- Markdown 子集刻意保持扁平：不支持嵌套列表、原始 HTML、图片。
- `Ctrl+R`/`Cmd+R` 只在输入框获得焦点时拦截；在页面其他地方浏览器仍会正常刷新。
- 插件语言覆盖插件自己的界面（搜索面板、历史胶囊、设置页这些组件内的文案）；设置页外层的 DSH 页面标题、侧栏骨架由宿主按 DSH 语言显示。
- 设置页每次打开时读取一次设置文件；直接手改文件后，需要重新打开设置页或重启插件才会反映。
